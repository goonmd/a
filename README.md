# Instagram Clone

순수 HTML / CSS / JavaScript로 만든 인스타그램 클론입니다.
백엔드나 빌드 도구 없이 GitHub Pages에 그대로 올리면 바로 작동합니다.

## 구현된 기능
- 게시물 피드 (좋아요, 더블클릭으로 좋아요, 댓글 작성/열람, 저장(북마크))
- 스토리 열람 기능 (여러 장 넘기기, 자동 진행, 좌우 탭으로 이전/다음, 열람 여부 표시)
- 프로필 페이지 (게시물 그리드, 팔로우 버튼, 프로필 클릭 시 이동)
- 게시물 클릭 시 상세 모달 (이미지 + 댓글 전체 보기)
- 좋아요/댓글/팔로우/저장/스토리 열람 상태는 브라우저 `localStorage`에 저장되어 새로고침해도 유지됨
- 5명의 사용자 계정, 총 15개의 게시물

## 폴더 구조
```
index.html          메인 피드 페이지
profile.html         프로필 페이지 (?u=아이디 로 사용자 구분)
css/style.css        전체 스타일
js/data.js            ★ 사용자·게시물·스토리 내용 (텍스트/이미지 경로 수정은 여기서)
js/storage.js         좋아요/댓글/팔로우 등 localStorage 저장 로직
js/icons.js           SVG 아이콘 모음
js/shared.js          공용 렌더링 로직 (좋아요, 댓글, 모달, 스토리 뷰어)
js/main.js            피드 페이지 렌더링
js/profile.js         프로필 페이지 렌더링
images/               사진을 넣는 폴더 (images/README.md 참고)
```

## 내용 채우기
1. **이미지**: `images/README.md` 에 적힌 정확한 파일명으로 사진을 넣으세요.
2. **텍스트**: `js/data.js` 를 열어 `username`, `name`, `bio`, `caption`, `comments` 등을
   원하는 내용으로 바꾸세요. 파일 상단에 한글로 설명이 달려 있습니다.
3. 게시물/스토리를 더 추가하고 싶으면 `POSTS` 배열이나 각 유저의 `stories` 배열에
   항목을 하나 더 추가하면 됩니다.

## 로컬에서 확인하기
그냥 `index.html` 파일을 브라우저로 열어도 되지만, 일부 브라우저는 보안 정책상
로컬 파일(`file://`)에서 스크립트를 막을 수 있습니다. 그럴 땐 아래처럼
간단한 로컬 서버를 켜서 확인하세요.

```bash
# 이 폴더 안에서 실행
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## GitHub Pages로 배포하기
1. 이 폴더 전체를 GitHub 저장소에 업로드(push)합니다.
2. 저장소의 **Settings → Pages** 로 이동합니다.
3. **Source** 를 `main` 브랜치, 루트(`/`) 폴더로 설정하고 저장합니다.
4. 잠시 후 `https://아이디.github.io/저장소이름/` 주소로 접속하면 사이트가 열립니다.

## 참고
- 학습/포트폴리오 목적의 클론 프로젝트입니다. 실제 Instagram과는 무관하며,
  로그인, 서버 저장, 실시간 알림 등 백엔드가 필요한 기능은 포함되어 있지 않습니다.
- 좋아요/댓글 등의 데이터는 오직 이 브라우저(이 기기)에만 저장됩니다. 다른 사람이
  같은 사이트에 접속해도 서로의 데이터는 공유되지 않습니다.
